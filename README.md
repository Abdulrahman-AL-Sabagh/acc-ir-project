# Compiler Optimizations on IR

This repository contains basic starter code for the
project option 2 of the Advanced Compiler Construction module.

### Main Code

 - ir: The MiniLanguage grammar and `MiniLang.java` to test it

 - tests: example programs of the MiniLanguage

 - .github: Automatic testing setup using GitHub Actions

### Scripts

 - `./run.sh <filename.ml>` runs the parser on a Mini Language program to check its syntax
